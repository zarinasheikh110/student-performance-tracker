# Student Performance Tracker

## 📌 Project Overview
This project is an Excel-based Student Performance Tracker developed to analyze student academic performance.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Conditional Formatting
- Data Validation

## 📂 Dataset
The dataset contains:
- Student Name
- Marks
- Attendance
- Grades
- Performance

## 📊 Features
- Student performance analysis
- Grade calculation
- Attendance tracking
- Interactive dashboard
