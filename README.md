# Online Retail Sales Analysis

## 📌 Project Overview
This project is an Excel- and SQL-based Online Retail Sales Analysis project developed to analyze sales performance, customer behavior, products, and country-wise revenue.

## 🛠️ Tools Used
- Microsoft Excel
- SQL
- Pivot Tables
- Charts
- Dashboard

## 📂 Dataset
The dataset contains:
- Invoice Number
- Product Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country

## 📊 Features
- Sales and revenue analysis
- Top-selling product analysis
- Country-wise sales analysis
- Customer behavior analysis
- Monthly sales trend analysis
- Interactive Excel dashboard
- SQL queries for business insights
